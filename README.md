# WebOS

A fully functional web-based operating system built with HTML, CSS, and JavaScript!

## Features
- Draggable windows
- Live clock in the top bar
- Notes app
- Calculator app
- Theme switcher

## How to test
Click the icons on the desktop to open the apps. Drag the windows around by their grey title bars, and close them using the red 'X' button.
